# Atividades — Sistemas Distribuídos

Repositório dedicado à implementação prática de algoritmos de sincronização e coordenação em Sistemas Distribuídos.

## Atividades

- **Algoritmo de Cristian:** sincronização de relógios considerando o tempo de ida e volta da comunicação.
- **Algoritmo de Berkeley:** sincronização de relógios por meio da média dos horários dos processos.
- **Eleição de líder:** escolha de um líder utilizando identificadores (IDs) e troca de mensagens entre processos.

## Objetivo

Compreender e aplicar conceitos fundamentais de sincronização de relógios, comunicação entre processos e coordenação em Sistemas Distribuídos.

## Tecnologias

- Python
